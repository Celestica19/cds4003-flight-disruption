# GitHub upload and deployment checkpoints

This is a technical setup guide. The uploaded brief requires Python, GitHub and Streamlit; the pasted rubric separately requires RapidMiner. Confirm which assessment applies with your instructor. Repository setup can proceed while that is clarified.

1. Sign in at https://github.com/new?name=cds4003-flight-disruption&visibility=public
2. Create the repository. Keep the options to generate a README, .gitignore or licence unchecked, because the package supplies its own project files.
3. Extract CDS4003_GitHub_Upload_Ready.zip on your computer.
4. On the new repository page choose the link to upload an existing file, or Add file then Upload files if that menu is shown.
5. Open the extracted CDS4003_GitHub_Upload_Ready folder and drag its CONTENTS into the upload area. Keep app, src, models, notebooks, docs, reports and data folders at the repository root alongside README.md and requirements.txt. Upload the extracted contents, not the ZIP file or its enclosing folder.
6. Use a descriptive commit message, such as Add project implementation and analysis evidence. Keep the AI assistance disclosure. This initial import is not a substitute for each student's own regular contributions.
7. After upload, check that the repository root shows app/streamlit_app.py, models/model.joblib, models/metadata.json and requirements.txt. Copy the repository URL for review.

Next checkpoint after repository review: create the Streamlit Community Cloud app from the same repository, branch main, main file app/streamlit_app.py, Python 3.12. The app's actual Streamlit runtime has not yet been verified. Capture build logs and genuine app screenshots; diagnose errors before calling deployment complete.

Final checkpoints: confirm public app access, enter team details and both URLs in the README, document real contributions and approvals, write the group and individual assessments in your own words, review all rubric items, then submit the required files on Blackboard.
